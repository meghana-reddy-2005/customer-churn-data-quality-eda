# Customer Churn – Data Quality and Exploratory Analysis

## Project Overview
This project focuses on auditing, cleaning, and exploring a synthetic customer churn dataset using Python. The objective is to identify data-quality issues, apply appropriate cleaning techniques, and discover meaningful patterns in customer behaviour.

## Objectives
- Profile dataset columns and data types.
- Identify missing values and duplicate records.
- Detect potential outliers.
- Clean and validate the dataset.
- Calculate summary statistics.
- Explore customer churn patterns using visualizations.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- VS Code

## Project Structure
- `data/` – Original dataset (subject to dataset redistribution permissions)
- `src/` – Python analysis scripts
- `outputs/` – Cleaned dataset and quality reports
- `charts/` – Exploratory analysis visualizations

## Methodology
1. Data loading and profiling
2. Missing-value and duplicate analysis
3. Outlier inspection
4. Data cleaning
5. Data validation
6. Exploratory Data Analysis
7. Visualization and reporting
